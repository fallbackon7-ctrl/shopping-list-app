# Interactive Shopping List

## Description
An interactive shopping list application built with HTML, CSS, and JavaScript. Users can add shopping items, record their prices, select items, mark items as purchased, edit existing items, and clear the list.

## Features
- Add items with prices.
- Select items and calculate their total cost.
- Mark items as purchased.
- Edit item names and prices.
- Clear the shopping list.
- Save and restore the list using browser local storage.
- Responsive layout for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

## How to Run
1. Clone or download this repository.
2. Open `index.html` in your browser, or open the folder in Visual Studio Code and use Live Server.
3. Add items and prices to start using the shopping list.
